## 2. 채널·프로젝트 개요

- **목적:** 아이디어가 생길 때마다 AI로 노래(작곡+보컬)와 영상을 만들어 새 유튜브 채널에 업로드
- **참고 스타일:** 심통봇(@S1M-T0NG-13OT) — AI 노래 + 유머/개그
- **유튜브 채널 ID:** `UCRmZShzKZzcPZJd4SHnsbWg` (기존 연필 소묘 채널과 별개)
- **실행 방식:** 스케줄(cron) 없음. 명령 한 번으로 실행, 업로드는 결과 확인 후 승인 시에만

## 3. 도구 현황

| 도구 | 용도 | 상태 |
|---|---|---|
| Suno (유료) | 작곡+보컬 | **공식 API 없음** → 가사는 사용자가 복사·붙여넣기, 브라우저 자동화로 대체 설계 필요 |
| kling.ai | 장면 영상 생성 | 공식 API 확인 (`https://api-singapore.klingai.com`, Bearer 키). **API 키 미발급** |
| ffmpeg | 노래+영상+자막 합성 | 완료·검증 |
| YouTube Data API | 업로드 | 스크립트 완료. **Google Cloud OAuth 클라이언트 미발급** |
| avocado CLI (MCP) | 노래 생성 보조 | 인증·등록 완료, 재시작 후 사용 가능 |

## 4. 파이프라인

```
아이디어 → 가사 초안 → Suno 생성 → 장면 프롬프트 → kling.ai 영상 → ffmpeg 합성 → 사용자 확인 → YouTube 업로드
```

| 스크립트 (로컬 `4.프로젝트/scripts/`) | 역할 | 검증 |
|---|---|---|
| `run_video.py "주제"` | 진입점, 중단 후 재실행 가능 | 통과 |
| `lyrics.py` / `scene_prompts.py` | 가사·장면 프롬프트 저장/로드 | 통과 |
| `compose.py` | 장면 연결 → 오디오 교체 → 자막 번인 | 통과 (h264/aac 확인) |
| `kling_client.py` | kling.ai 호출 | 부분 (키 발급 후 검증) |
| `youtube_upload.py` | 업로드 | 부분 (OAuth 발급 후 검증) |

참고: 이 환경은 `pip` 직접 실행 시 권한 오류 → `python -m pip install -r requirements.txt` 사용. Windows 콘솔 한글 깨짐은 UTF-8 stdout 재설정으로 수정됨.
